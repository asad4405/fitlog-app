# 💪 FitLog

FitLog is a simple workout library web app where users can browse different workouts, check workout details, add workouts to today's plan, and save workouts for later.



## 🌐 Live Website & GitHub

**Live Website:** https://fitlog-web-app.vercel.app

**GitHub Repository:** https://github.com/asad4405/fitlog-app



## 🛠️ Technologies Used

* Next.js
* TypeScript
* Tailwind CSS
* daisyUI
* React Icons



## ✨ Features

* Browse all workouts from the workout library
* View detailed information about each workout
* Add workouts to Today's Plan
* Save workouts for later
* Mark workouts as done
* Remove workouts from the plan
* Sort workouts by duration, calories, and rating
* Plan and Saved workout counters
* Toast notifications for actions
* Loading states while fetching workouts
* Custom 404 page
* Fully responsive for mobile, tablet, and desktop



## 📱 Responsive Design

The website is designed to work properly on:

* Mobile
* Tablet
* Desktop

The layout, workout cards, navbar, hero section, and My Plan page are responsive across different screen sizes.
